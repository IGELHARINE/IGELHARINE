## Automation Engineer · 김도성

I build crawlers, data collectors and multi-account chat tools, then ship and operate them end to end.
Most of the work is taking something a person repeats by hand and turning it into a program that runs unattended.

### Focus

Browser automation at scale — headless control, anti-bot evasion, session and token handling,
and the dashboards and desktop agents that sit on top of them.
